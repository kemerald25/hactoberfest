# **App Name**: ReplyIQ

## Core Features:

- Live AI Assistant: An interactive tool powered by Cloudflare AI providing professional, contextual 24/7 support for any business.
- Smart Context Ingestion: Interface tool for connecting business FAQs and documentation to provide the assistant with internal business knowledge.
- Lead Management System: Automated capturing of contact inquiries into a secure Supabase database for sales follow-ups.
- Premium Glassmorphism Interface: High-fidelity UI featuring blurred backdrop filters and glowing interactive cards built with Tailwind CSS.
- Dynamic Persona Editor: A control center for adjusting the tone and personality of your AI assistant to match corporate branding.
- Staggered Motion Effects: Polished enter animations using Framer Motion for a sophisticated, luxury digital agency feel.

## Style Guidelines:

- Primary color: Electric Cyan (#00D4FF) for a high-tech, trustworthy highlight against the dark palette.
- Background color: Deep Near-Black (#080C10) with a subtle navy undertone for a luxury SaaS aesthetic.
- Accent color: Cobalt Blue (#0084FF) to provide analogous contrast for depth and actionable UI elements.
- Headline font: 'Playfair' serif for an elegant, high-end display feel. Note: currently only Google Fonts are supported.
- Body font: 'PT Sans' humanist sans-serif for warmth and professional clarity. Note: currently only Google Fonts are supported.
- Thin-stroke Lucide icons in electric cyan with soft outer glows for a refined technical look.
- Generous white space (padding-y of 32 or more) and centralized glass-card components to maintain premium focus.
- Staggered fade-up and gentle scaling (easeOut, 0.6s) applied to cards to simulate a luxury cinematic entry.
